# physicsvkbot

Бот ВКонтакте для подготовки к ЕГЭ по физике (задания № 1–20) на базе `fastvk` и SQLAlchemy 2.0.

## Возможности

- Выдача заданий по номерам ЕГЭ (1–20) без повторов до полного прохождения банка.
- Проверка ответов, учёт прогресса и статистика по пользователям.
- Поддержка PostgreSQL и SQLite через SQLAlchemy 2.0.
- Встроенный HTTP healthcheck-сервер и запуск в Docker.

## Структура проекта

- `main.py` — точка входа и запуск бота.
- `src/` — обработчики команд, модели БД и бизнес-логика.
- `upload_tasks.py` — скрипт загрузки банка заданий в базу.
- `init.sql` — SQL-инициализация схемы базы данных.
- `tests/` — тесты.
- `Dockerfile`, `docker-compose.yml` — контейнеризация.

## Запуск

    cp .env.example .env  # при наличии локального .env настройте токены и DSN
    docker compose up -d --build

Локальный запуск без Docker:

    pip install -r requirements.txt
    python main.py
