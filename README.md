## 📖 Описание

> Бот делает акцент на **первую часть ЕГЭ по физике (задания 1–20)**, где требуется короткий текстовый или числовой ответ. 
> 
> Главная фишка проекта — **умная система выдачи и трекинга**: бот запоминает уже решенные учеником задачи и гарантирует, что не будет выдавать их повторно вплоть до полного исчерпания базы. Можно решать как случайные задачи из всего пула, так и прицельно тренировать определенный номер задания (от 1 до 20).

Сразу после ввода ответа пользователь получает мгновенную обратную связь: верный ли дан ответ, а также показ правильного ответа, если допущена ошибка. Все ответы сохраняются для личной статистики.

---

## ✨ Ключевые особенности

| Функция | Описание |
|---------|----------|
| 🎯 **Умная выдача** | Алгоритм отслеживает решенные задачи и выдает только новые |
| 👤 **Профили и статистика** | История успеваемости с разбивкой правильных ответов по каждому номеру задания |
| 📚 **База заданий** | Тренировка любых заданий с 1 по 20, поддержка прикрепленных иллюстраций в ВК |
| 🛡 **Администрирование** | Добавление новых заданий прямо из сообщества ВК (фото + ответ) |
| 🧹 **Управление данными** | Сброс профилей учеников и истории ответов прямо через диалог бота |
| 🏥 **Healthcheck Endpoint** | Встроенный HTTP-сервер на порту `$PORT` для стабильного развертывания на Render/Docker |

## 🛠 Стек технологий

* **Язык разработки:** `Python 3.11+`
* **Фреймворк ВК:** `fastvk`
* **База данных:** `PostgreSQL` / `SQLite`
* **ORM:** `SQLAlchemy 2.0` (через `asyncpg` / `aiosqlite`)
* **Инфраструктура:** `Docker` / `Docker Compose`
